**Stackryze Domains** は**複数の**ドメインサフィックスを運営し、開発者、学生、オープンソースコミュニティ向けに無料のマネージドサブドメインサービスを提供しています。

ドメインを取得し、任意のホスティングプロバイダーや独自のインフラへ接続できます。完全な所有権と管理権を持つことができます。

**すばやく構築。自由にデプロイ。ロックインなし。**

---

## Stackryze を選ぶ理由

目標はシンプルです。オンライン公開にかかる費用と複雑さをなくすことです。

- 無料のマネージドドメイン
- あらゆるホスティングプロバイダーや DNS プロバイダーに対応
- 学生、開発者、OSS プロジェクト向けに構築
- 透明性が高く、コミュニティ主導で信頼できるサービス

## 🏗️ アーキテクチャ
透明性は宣伝するものではなく、実践によって示すものだと考えています。そのため、Stackryze Domains と Stackryze DNS を支えるインフラとシステムを公開し、コミュニティからのフィードバック、質問、検証を歓迎しています。
![Stackryze アーキテクチャ](architecture.png)

## 🌐 DNS インフラ

Stackryze Domains の名前空間は、信頼性と低遅延を実現するため、世界各地に分散したネームサーバーによって支えられています。

- **ns1.stackryze.com** — プライマリ DNS サーバー（米国ニューヨーク市）
- **ns2.stackryze.com** — セカンダリ DNS サーバー（ドイツ・ニュルンベルク）
- **ns3.stackryze.com** — セカンダリ DNS サーバー（インド・ハイデラバード）
